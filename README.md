# Bommu Manoj Madhu Kumar - Software Engineer Portfolio

Live Demo: [https://manojbommu.github.io/portfolio/](https://manojbommu.github.io/portfolio/)

A modern, high-performance, cyber-themed portfolio website showcasing full-stack applications, C++ Data Structures & Algorithms, interactive in-browser simulators, and certifications.

## 🚀 Key Features
- **Luminous Cyber Aesthetic:** Custom midnight UI, animated floating glowing mesh orbs, and glassmorphism.
- **Dynamic Color Theme Switcher:** Instant theme switching between Cyber Cyan, Neon Violet, Emerald Matrix, and Solar Amber.
- **Interactive Project Sandboxes:**
  - **Property Management System:** Live RBAC simulator previewing 3-role permissions (Admin, Manager, Tenant) with architecture modal.
  - **Polynomial Calculator (DSA):** Real in-browser polynomial calculus & algebraic parser ($d/dx$, degree, add, subtract).
  - **AI Loan Eligibility Bot:** Interactive conversational bot analyzing income, expenses, and debt-to-income to estimate loan capacity.
- **Mobile First & Fully Responsive:** Seamless touch experience across phones, tablets, and desktops with zero overflow.
- **Education & Credentials:** Complete academic timeline (Lovely Professional University, Tirumala College, De Paul High School) and hackathon achievements (Top 5 / 50 teams).

## 🛠️ Built With
- **HTML5 & Vanilla CSS3** (Custom Keyframe Animations & CSS Variables)
- **Vanilla JavaScript** (Zero external dependencies)
- **Google Fonts:** Space Grotesk, Plus Jakarta Sans, Fira Code
